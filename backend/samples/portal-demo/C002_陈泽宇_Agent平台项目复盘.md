## 项目一：统一 Agent 运行平台

**背景**：多个业务团队各自接入大模型，存在密钥分散、调用不可观测、工具协议不统一的问题。

**职责**：负责平台架构、运行时、工具注册中心和可观测性。

**关键动作**：

- 设计“会话线程 + 运行 + 中断恢复”的运行时模型，统一接入 LangGraph Agent Server。
- 建设工具注册中心，支持参数 Schema 校验、超时、重试、熔断和审计，工具调用失败率从 4.7% 降到 0.9%。
- 接入 Prometheus 与 OpenTelemetry，按租户、图、节点、工具维度记录耗时和错误码。
- 设计租户与权限上下文注入机制，模型和工具参数都不能覆盖服务端注入的 tenant_id。

**结果**：平台承载 8 个业务 Agent，日均运行 1.6 万次，P95 运行耗时下降 32%，全年无越权访问事故。

## 项目二：模型网关与成本治理

**职责**：统一模型路由、配额、缓存和降级。

**结果**：通过小模型路由和语义缓存，模型成本下降 27%；高峰期自动降级到备用模型，可用性保持 99.9%。
